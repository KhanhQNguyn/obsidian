## Summary

Môn nhập môn Embedded Systems — thiết kế hệ thống số dựa trên microprocessor, dùng mô phỏng + hardware thật. Là tiền đề cho Embedded System Design and Implementation (EEET2096).

- **Credit points:** 12
- **College/School:** STEM / Engineering
- **Course Coordinator (thời điểm bản này):** Shruti Nirantar — shruti.nirantar@rmit.edu.au
- **Không tính vào WAM** (Honours program)

## Notes

### Nội dung chính
- Introduction to Digital Hardware Technologies
- Introduction to Computer Systems & Architectures
- Introduction to Assembler-level firmware for Embedded Systems
- Introduction to Interfacing Computer Systems to External Hardware
- Dùng C/C++ để implement functionality trên embedded hardware

### Assumed Knowledge
- Hiểu cơ bản digital logic systems + physical implementation (tương đương OENG1206 Digital Fundamentals)
- Code được bằng một ngôn ngữ HLL (C/C++ hoặc Java)
- Hiểu tổng quan về computing systems và các loại interface
- Biết tự research (textbook, internet)

### Learning activities
- Xem lại lecture ghi hình (có demo/ví dụ)
- Làm lectorial questions + laboratory projects
- Viết lab report (firmware + embedded design problems)
- Tự học thêm

### Learning Outcomes (CLO)
1. Đọc hiểu instruction set của microcontroller, đánh giá cách instruction được thực thi vật lý (8-bit microcontroller)
2. Thiết kế, test, đánh giá giải pháp embedded systems cho vấn đề thực tế bằng industry-standard hardware
3. Nhận diện đặc điểm chính của embedded systems (hardware) và giải thích được chức năng
4. Phát triển software cho embedded devices bằng assembler và C/C++
5. Giao tiếp rõ ràng về quy trình phát triển firmware cho đối tượng chuyên môn
6. Làm việc nhóm hiệu quả (member hoặc leader)
